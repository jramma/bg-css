# Web estática con fondo animado

Esta web la hice en 2024. Es un portfolio rápido y sencillo. Si quieres tener los datos de tu github en el apartado `/projects/`tienes que editar la variable en `consts.ts` por tu nick de github.

```ts
export const GITHUB_USERNAME = "<TU_NICK_DE_GITHUB>";
```

Puedes ver una demo en [bgcss.casset.cat](https://bgcss.casset.cat/)


## Ejecutar en local:

1. pnpm i
2. pnpm run dev
